# Analysis for blog: Questions about Lithos's first ERW credit issuance 
These notebooks reproduce the back-of-envelope analysis done to gut-check Lithos's claim of 8.3 tonnes/ha/yr of gross CDR. 

- `surface-area.ipynb` analyzes how much surface area is required to reach the inferred dissolution fraction given a range of dissolution rates. 
- `export-fluxes.ipynb` analyzes the DIC and ALK export required to achieve 8.3 tonnes/ha/yr gros CDR.
